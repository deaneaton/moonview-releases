# MoonView Studios updates

Finished versions of the MoonView Studios app, which installed MoonView programs download by themselves (`latest.json`). The program itself is under Releases. The source is private.

Sound packs inside the app: FreePats and the Versilian Community Sample Library (CC0); the Rock kit is MuldjordKit by Lars Muldjord (CC BY 4.0), shortened, faded, mixed to mono and re-encoded for MoonView.
